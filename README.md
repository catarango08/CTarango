# ElectricPro — Side Job Manager

A web application for electricians to manage side jobs: scoping work, building bids, and scheduling job days.

## Features

- **Dashboard** — pipeline overview, revenue tracking, upcoming schedule at a glance
- **Job Management** — track jobs through the full lifecycle (Prospect → Invoiced)
- **Scoping** — document work items and site notes per job
- **Bidding** — calculate labor + materials with markup; mark bids sent/accepted/rejected
- **Scheduling** — add work days with start/end times, track upcoming vs past entries

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- localStorage persistence (no backend required)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```
