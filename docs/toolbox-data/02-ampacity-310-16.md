# Allowable ampacity: 60/75/90°C, Cu and Al/CCA
Conditions: no more than 3 current-carrying conductors in a raceway, cable or earth, at 30°C ambient.

**Table number:** 2011 and 2017 use Table 310.15(B)(16). 2020 and 2023 use Table 310.16. The values are the same in all three editions.
