# NEC Field Toolbox Data: 2023 (primary), with 2017/2011 differences

Each table has its own file (01–17), and each file cites its sources. NFPA's free-access text could not be used directly, so the values were checked against manufacturer references (OmniCable, Cerrowire, Eaton Bussmann, Raco/USESI), NECA-IBEW reprints, IRC/UpCodes, municipal job aids (City of Carmel) and trade/education references.

## Edition value differences found
- **Table 300.5:**
  - 2011 heading "0–600 V"; 2017+ "0–1000 V".
  - 2017 added Column 5 footnotes for listed low-voltage lighting.
  - 2023 added EMT to Column 3, plus Note 6 (358.10).
  - No cover depths changed.
- **430.52:** the row label changed (Design E → Design B energy-efficient → Design B premium efficiency). The percentages did not change.
- **314.16(B) counting rules:** the loop-counts-as-2 rule, the >2 in. device rule, and the isolated-EGC 1/4 allowance appear in 2017 and 2023. Whether they appear in 2011 is UNVERIFIED.
- **All other tables:** no numeric differences between 2011, 2017 and 2023 were found.

## UNVERIFIED items
1. 310.16 (2023): not compared row by row with a primary NFPA 2023 text. Secondary sources agree.
2. 240.4(D)(1)/(2): the 18/16 AWG condition wording.
3. 314.16(B): which 2011 counting rules existed (see above).
4. Ch.9 Table 4: PVC Sch 40 values for 2-1/2 through 4 (from a search synthesis of the NECA reprint).
5. 430.52: the exact row labels in each edition.
6. 430.22: the subsection lettering in each edition.
7. Table 300.5: the 2023 designation (300.5 vs 300.5(A)), and the 4 in. slab Col 4/5 split in every edition.
8. 250.66: the 2023 footnote wording.
9. 250.122: the 2500–6000 A rows, especially 5000/6000 A Al = 1250.
10. 220.82(C): the 2023 item order, and the "100 A or more" wording.

## Data notes
- 314.16(A), 4x1-1/4 round/oct, 8 AWG = 4. One PDF text extraction read 5; two other sources give 4.
- Pre-2011 ampacity reprints (1999/2002) differ in several cells and were rejected. Examples: Cu 60°C 600 kcmil 355 vs 350; Al 300 kcmil 190/255 vs 195/260; Al 6 AWG 90°C 60 vs 55.
