# Table 430.52 (2011/2017) / Table 430.52(C)(1) (2020+): Max motor branch SC/GF protection, % of FLC
| Motor type | Non-time-delay fuse | Dual-element (TD) fuse | Instantaneous-trip CB | Inverse-time CB |
|---|---|---|---|---|
| Single-phase | 300 | 175 | 800 | 250 |
| AC polyphase squirrel cage, other than Design B energy-efficient | 300 | 175 | 800 | 250 |
| Design B energy-efficient (labeled Design E in pre-2005 tables) | 300 | 175 | 1100 | 250 |
| Synchronous | 300 | 175 | 800 | 250 |
| Wound rotor | 150 | 150 | 800 | 150 |
| DC (constant voltage) | 150 | 150 | 250 | 150 |

If a value is not a standard size, the next higher standard size is permitted (430.52(C)(1) Exc. 1). If the motor still won't start (Exc. 2):
- Non-time-delay fuses ≤600 A and Class CC fuses: up to 400%
- Time-delay fuses: up to 225%
- Inverse-time CB: up to 400% for ≤100 A FLC, 300% above 100 A
- Instantaneous trip: up to 1300%, or 1700% for Design B energy-efficient (430.52(C)(3))

**Sources:** Eaton/Cooper Bussmann "Motor Branch Circuit Protection" (2005 table, percentages). NORDIX 430.52 chart and EC&M "NEC Requirements for Motors" (search synthesis).
**UNVERIFIED:** the exact motor-type row labels in each edition. The Design B energy-efficient row wording changed in 2014 and 2017 ("Design B premium efficiency"), and the table number changed in 2020. The percentages are believed unchanged.
